# PROTOTYPE: choose the Astro theme

Throwaway prototype for [Choose the Astro theme](https://github.com/nemchik/nemchik/issues/387). It lives only on the `prototype/astro-theme` branch and is never merged.

Three candidate themes, each lightly customized (config, nav, homepage content) with the same real content:

- `a-astrowind/`: [AstroWind](https://github.com/arthelokyo/astrowind), from its `homes/personal.astro` demo
- `b-dante/`: [Dante](https://github.com/JustGoodUI/dante-astro-theme)
- `c-astropaper/`: [AstroPaper](https://github.com/satnaing/astro-paper)

Run `npm run prototype` here, then open <http://127.0.0.1:4320/?variant=A>. The yellow bar (or the ← and → keys) switches between themes. Everything binds to 127.0.0.1 only.
