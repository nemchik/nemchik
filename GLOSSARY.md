# nemchik

Eric Nemchik's public presence on GitHub and the web, both maintained from this one repository.

## Language

**Profile README**:
The `README.md` GitHub shows at the top of github.com/nemchik. A short card that points to the Site.
_Avoid_: readme (unqualified), profile page

**Site**:
The static website served at nemchik.com, built from this repository. Its content is independent of the Profile README.
_Avoid_: docs, documentation, blog, webpage

**Homepage**:
The Site's front page at nemchik.com/.
_Avoid_: index, landing page, About Me

**PR preview**:
A temporary, browsable build of the Site from a pull request, published so the change can be seen before it merges.
_Avoid_: staging, preview deploy, review app
